# WarmFeng (暖枫)

WarmFeng is a life-logging app with an anime (2D) "healing handbook" aesthetic. It features handbook-style layouts, gentle comforting copy, focus and breathing exercises, food and nutrition tracking, and a countdown-days module.

## Tech stack

Next.js with the React framework, React 19 with TypeScript, and Tailwind CSS. Capacitor is used to package the app for Android. It runs fully offline and locally. All data is stored in the browser or the app's local storage. There is no backend, no account, and no cloud sync.

## Run the web version locally

You only need Node.js (LTS recommended). No Android setup is required.

Install dependencies with:

npm install --legacy-peer-deps

This is required because react-roughviz declares a peer dependency on React 16, so a plain npm install will fail.

Start the dev server with:

npm run dev

Then open http://localhost:3000 to preview.

Build the production version with:

npm run build

then:

npm run start

## Package as an Android app (optional)

This step is much heavier than the web version. It requires Android Studio, JDK 21, and your own signing keystore. You do not need it just to try the app or read the code.

First run:

npx cap add android

to generate the Android project. Then run:

npm run cap:sync

to sync the web build into the Android project. Open the android directory in Android Studio, or run:

npm run apk:debug

for a debug build, or:

npm run apk:release

for a release build (the release build needs your own signing keystore). Note that the android directory is not tracked by git by default. It is the native project generated by cap sync, so contributors regenerate it locally.

## Project structure

app: Next.js entry point.
components: UI components. The single-page app switches pages with nav.
lib: utilities and data logic, including nutrition calculation, the food library, and the mind map.
public: static assets, including the China foods data china-foods.json.
hooks: React hooks.
